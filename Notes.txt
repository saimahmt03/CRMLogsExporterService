REQUIREMENT REFERENCE

1.Right-click References.

* CRMLogsExporterService

How to add:
1. Right-click to Console-App Test
2. Select Add
3. Select Reference
4. In Reference Manager Select Projects
5. Check CRMLogsExporterService
6. Click OK
